# Schwung Monomodule

[Monomodule](https://github.com/shnolk/monomodule) — a chip-level emulation of the Elektron Monomachine
(SFX-6 / SFX-60) — ported to [Schwung](https://github.com/charlesvestal/schwung) on Ableton Move.

Work in progress. Needs the Monomachine OS 1.32B file, a free download from Elektron; it is never
included.

`scripts/build.sh mnm-bench` cross-compiles a CPU benchmark: `mnm-bench <os.syx> [seconds] [cpu]`.
